🚀 THREE SIMPLE STEPS TO BUILD
════════════════════════════════════════════════════════════════════════════

1. INSTALL DOCKER (first time only)
   • Visit: https://www.docker.com/products/docker-desktop
   • Download for your Mac (Intel or Apple Silicon)
   • Install and launch

2. VERIFY SETUP
   • Run command: ./setup-docker.sh

3. BUILD SPORTMHI
   • Run command: ./build-docker.sh
   • Wait 1-5 minutes (first build takes longer)
   • Your SportHMI.jar is ready!

🔧 COMMON COMMANDS
════════════════════════════════════════════════════════════════════════════

Build SportHMI:
  ./build-docker.sh

Verify Docker setup:
  ./setup-docker.sh

Enter container interactively:
  docker run -it -v $(pwd):/workspace sporthmi-builder:latest bash

Clean rebuild:
  docker rmi sporthmi-builder:latest && ./build-docker.sh

View Docker images:
  docker images | grep sporthmi


❓ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

"Docker not installed"
  → Install from: https://www.docker.com/products/docker-desktop

"Docker daemon not running"
  → Launch: /Applications/Docker.app

"Permission denied"
  → Run: chmod +x build-docker.sh

"Something else is broken"
  → Check BUILD_MACOS_DOCKER.md (Troubleshooting section)
